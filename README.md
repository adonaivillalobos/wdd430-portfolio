# WDD 430 Portfolio

Personal portfolio site built for WDD 430, showcasing projects and skills using Next.js, TypeScript, and Tailwind CSS.

**Live site:** https://wdd430-portfolio-tau.vercel.app

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/` — pages (Home, About) and the API route
- `components/` — reusable components (Header, Footer, ProjectCard, ProjectList, SkillCard)
